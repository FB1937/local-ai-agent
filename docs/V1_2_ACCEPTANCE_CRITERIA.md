# v1.2 구현 및 완료 기준

- [ ] 현재 날짜를 검색 계획에 전달
- [ ] 질문의 시간 민감도에 따라 검색 기간 설정 또는 미적용
- [ ] URL 정규화 및 중복 제거
- [ ] 검색 결과에 안정적인 source ID 부여
- [ ] 인용 source ID 존재 여부 검사
- [ ] 검색 실패 시 출처를 만들어내지 않고 한계 표시
- [ ] 최대 1회 재검색
- [ ] HYBRID에서 일반 개념과 검색 근거 내용을 분리
- [ ] 단계별 실행 시간과 오류 기록
- [ ] v1.1 회귀 테스트 전부 통과

## P1 — 가능하면
- [ ] 공식 문서/정부/학술/언론/기업/블로그 등 출처 유형 분류
- [ ] 게시일이 없는 자료를 최신으로 간주하지 않기
- [ ] 상충 자료의 출처 신뢰도와 날짜 비교
- [ ] 복합 질문 검색어 분해

## P2 — 후속 버전
- 웹페이지 본문 수집, Cross-Encoder reranking, 별도 LLM 의미 검증, 벡터 DB

## 평가 원칙
라우팅·검색·답변 품질을 분리 평가합니다. Precision@5는 관련 문서 골드셋이 있을 때만 계산합니다. Citation validity와 Groundedness는 서로 다른 지표입니다. 모델 자체 confidence는 보정된 확률이 아닙니다.

## 초기 통과 기준
- 결정론적 단위 테스트 100% 통과
- 존재하지 않는 source ID 인용 0건
- 재검색 최대 1회
- URL 중복 제거 테스트 100% 통과
- v1.1 회귀 테스트 100% 통과
- 의미적 품질 목표는 골드셋 기준선 측정 후 설정
